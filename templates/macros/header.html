**The order is load-bearing.** The checkbox reveals the search form and the nav through the sibling combinator (`~`), which only reaches elements that come after it inside the same parent. Move it after the nav and the menu silently stops opening. No JavaScript. The first version of this toggled a class from a script and shipped a hamburger that rendered and then did nothing — a control that needs a script to function has a failure mode where it is visible, looks interactive, and is not. A checkbox has no such state: the browser toggles `:checked` itself, so "the script did not run" cannot happen. #} {% macro nav_toggle(label='Menu') %} {# The checkbox is the state and is never display:none — that would take it out of the tab order and make the menu keyboard-unreachable.
