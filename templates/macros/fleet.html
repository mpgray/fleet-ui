A tag that four codebases must emit identically is exactly the thing this file already exists to hold — the same argument the cross-link nav above makes, for the same reason. WHAT IT IS FOR. This tag is what makes that detectable. PASS THE SLUG OF THE BLOG, not of the pack, the game or the tool.
